# GoTrips eSIM Installation Guide

## Intent

Create a clear, faceless installation guide that helps a non-technical traveller install a GoTrips eSIM confidently on either iPhone or Android.

## Audience

International travellers who have already bought an eSIM and need practical setup help before or during their trip.

## Core message

Installing an eSIM is quick when the customer has Wi-Fi, keeps the QR code or activation details available, follows the correct device menu, and does not delete the profile after installation.

## Content

- Begin with a short preparation checklist: stable Wi-Fi, eSIM-compatible unlocked phone, QR code on a second screen or activation details.
- Show the iPhone path: Settings → Cellular / Mobile Data → Add eSIM → Use QR Code.
- Explain the same-device fallback: use a saved QR image or enter the activation details manually when the device offers that option.
- Show the Android path: Settings → Network & internet / Connections → SIMs / SIM manager → Add eSIM / Add mobile plan.
- Finish with activation checks: label the line, select the travel eSIM for mobile data, enable data roaming only when the plan instructions require it, and keep the eSIM profile installed.
- State that menu wording varies by phone model and software version.

## Format

- Workflow: faceless explainer
- Flow: autonomous production
- Storyboard checkpoint: omitted
- Duration target: 70–80 seconds
- Language: English
- Destination: website and purchase-email help link
- Canvas: 1920×1080, 16:9
- Narration: calm, practical, reassuring
- Visual direction: premium black background, warm metallic gold accents, clean device UI diagrams, restrained motion, large readable type
- Audio: subtle modern technology bed under narration; no vocals

## Success criteria

- A customer can identify the correct setup path for iPhone or Android after one viewing.
- The same-device QR-code problem is addressed without implying that every handset exposes identical controls.
- No real customer data, ICCID, activation code, or reusable QR code appears.
- The composition passes HyperFrames checks and renders deterministically.
