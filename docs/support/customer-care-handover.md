# Customer-care handover — GoTrips support tickets

## Daily routine

1. Open **Manager → Support Tickets** at the start of the shift.
2. Work overdue tickets first, then tickets awaiting a first response, then the oldest open ticket.
3. Read the customer's original problem and source page before replying.
4. Assign the ticket to yourself and send a useful first response. Do not send a placeholder only to improve the response-time metric.
5. Set **Waiting for customer** when information is needed, **Open** while the team owns the next action, and **Resolved** only after the issue is handled.
6. Recheck waiting and idle tickets before the shift ends.

## Response standard

- Acknowledge the exact issue in the first sentence.
- State the next action and realistic timing.
- Ask only for information that is still missing.
- Never request passwords, card numbers, one-time passwords or full payment credentials.
- Keep all customer-visible updates inside the ticket so another teammate can continue without calling the previous agent.

## Escalation

- Payment captured but product not delivered: priority **Urgent** and escalate immediately.
- eSIM QR/installation problem: confirm device compatibility, whether the QR was scanned, and the exact on-screen error; never issue a replacement before checking the provider order.
- Visa/deposit/refund issue: include the application/order reference and escalate to the product owner.
- Suspected fraud, threats, legal claims or data exposure: stop normal handling and escalate to a manager.

## Shift handover

Before leaving, make sure every open ticket has a current status, assignee and a message stating the next action. The dashboard's overdue and idle counts must be reviewed with the incoming agent.
