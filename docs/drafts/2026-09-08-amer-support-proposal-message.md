# Draft message to Amer — support proposal

Hi Amer,

I have converted the support requirement from our 3 September call into a complete workflow.

The website chatbot will become our own ticket window. When a customer opens it, they can either create a new ticket or track an existing one. For a new ticket, the window asks for the problem first, then email and phone, and immediately gives the customer a ticket ID together with our support hours and expected response time.

Every ticket will always appear in a dedicated Support Tickets section in the manager portal. The support person will also receive it by email. The WhatsApp integration is being kept ready; once you provide the WhatsApp Business API credentials and destination number, it can be activated without rebuilding the ticket flow.

The manager view will monitor both sides: customer activity and our team's performance. It will show tickets waiting for a first reply, overdue/idle tickets, average first-response time, assignee, status and the full conversation. This also leaves a proper record for handing support from me to a future customer-care employee.

I have used a default first-response target of four hours and default support hours of Monday–Saturday, 9:00 AM–6:00 PM UAE time. Both can be changed in the manager portal.

Please let me know if you want a different SLA or support schedule; the rest follows the workflow agreed in the call.
